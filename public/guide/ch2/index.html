Chapter 2

Getting Started

Learning objectives

  1. Log in to SAP Business One.
  2. Identify the parts of the user interface and basic navigation tools.

1 · How to log in

  1. Open any web browser (Chrome, Firefox, Edge).
  2. Type the URL from your instructor in the address bar and press Enter.
  3. The SAP Business One log-in page appears.
  4. Select the company your instructor provides.
  5. Log in with the User ID & Password for your assigned branch.

📱 On a phone, turn on “Desktop Site” so the interface displays properly.

Beyond the manual — why branches?

In a class, everyone shares one company file, so each student gets a numbered branch (Branch 1–42) that keeps your work separate from your classmates'. Logging into the wrong branch means working in someone else's data — always use the one assigned to you.

2 · The user interface

PartWhereWhat it does
Menu BarTop of screenWindows menus (File, Edit, Window, Help) plus general SAP functions.
Tool BarUnder the menu barIcon buttons for commonly-used functions — shortcuts also found in the menu bar.
Modules MenuMain navigation panelLists all modules and their options in a tree structure.

Three facts about the Modules Menu

  • Arranged in the same order as the Main Menu.
  • Cannot be modified.
  • May be inactive for unauthorized users (you only see what you're allowed to).

3 · Change your user name & password

From the toolbar, open My Personal Settings (the User Set-up window appears):

  1. Change the User Name field to your own name.
  2. Click beside the Password field to personalize it.
  3. Enter the old password, then your new password in the Password and Confirm fields.
  4. Click OK, then Update.

4 · Set your branch name

Navigate to:

Administration▸Setup▸Financials▸Branches

  1. In the Branches Setup window, find your assigned branch.
  2. Change Branch Name and Branch Name (Foreign) to your own name.
  3. Click Update.

5 · Basic customization (display settings)

Set how things display:

Administration▸System Initialization▸General Settings

On the Display tab, set:

SettingValue
LanguageEnglish (United States)
Time Format12H
Date FormatMM/DD/YYYY

Then click Update and OK.

🔎 Font size/style can’t be changed inside SAP — increase your browser’s zoom % instead.

Key terms

Company
The database/file you select and log into.
Branch
Your assigned workspace that keeps your data separate.
Menu Bar
Top menus: File, Edit, Window, Help + SAP functions.
Tool Bar
Row of icon shortcut buttons.
Modules Menu
Tree-structure navigation of all modules.
